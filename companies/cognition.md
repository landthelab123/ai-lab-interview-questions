# Cognition interview questions and loop (2026)

5 engineering interview questions candidates report from Cognition, most recently in Sep 2026. Worked answers, a rubric per level and a prep plan: **[Cognition on Land the Lab](https://landthelab.com/companies/cognition)**.

## The loop

A recruiter or hiring manager call, a coding assessment or live coding screen, then an onsite. The CEO has said engineering candidates build their own end-to-end coding agent in six to eight hours. Most dated reports come from Windsurf (Codeium) pipelines before the 2025 acquisition.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen |  | Call with a recruiter or the hiring manager |
| 2 | Online assessment |  | Timed online coding assessment |
| 3 | Coding screen |  | Live coding |
| 4 | Build day | 480 min | Build your own end-to-end coding agent from scratch |
| 5 | System design |  | Design discussion |
| 6 | Project deep dive |  | Conversation about a system you built: where it broke and what you would change |

What each round grades, its AI policy and how to prep: [Cognition interview process](https://landthelab.com/companies/cognition).
