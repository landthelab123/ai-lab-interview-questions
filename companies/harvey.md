# Harvey interview questions and loop (2026)

23 engineering interview questions candidates report from Harvey, most recently in Sep 2026. Worked answers, a rubric per level and a prep plan: **[Harvey on Land the Lab](https://landthelab.com/companies/harvey)**.

## The loop

Recruiter and hiring manager calls, a coding phone screen, then an onsite of coding, LLM-application system design, behavioral and a project walkthrough; roughly half the bar is ordinary engineering and half is turning messy legal work into something a model does reliably. Two to five weeks from the recruiter call to an offer is typical.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen | 30 min | Call |
| 2 | Hiring manager | 45 min | Call with the hiring manager |
| 3 | Technical phone screen | 60 min | Live coding in a shared editor |
| 4 | Coding | 60 min | Live practical coding |
| 5 | System design (LLM applications) | 60 min | Design discussion on a whiteboard or doc |
| 6 | Behavioral | 45 min | Conversation |
| 7 | Project walkthrough | 60 min | Walk through a project you built, then questions |
| 8 | Unconfirmed |  |  |

What each round grades, its AI policy and how to prep: [Harvey interview process](https://landthelab.com/companies/harvey).
