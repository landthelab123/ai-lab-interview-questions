# Sierra interview questions and loop (2026)

9 engineering interview questions candidates report from Sierra, most recently in Nov 2026. Worked answers, a rubric per level and a prep plan: **[Sierra on Land the Lab](https://landthelab.com/companies/sierra)**.

## The loop

A recruiter call and one coding screen, then an onsite built around AI coding tools: a three-and-a-half-hour AI-native build (plan a project with the interviewer, build it alone for two hours with coding agents, then demo it and defend the path to production), a code ownership round (take over a teammate's PR and make it shippable, or add a feature to an existing app) and a work-experience conversation with the hiring manager. Agent engineer loops have used a take-home support agent and its presentation in place of the build. Two to five weeks from the first call to an offer is typical.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen | 30 min | Call |
| 2 | Technical phone screen | 60 min | One live coding problem in Python or TypeScript |
| 3 | AI-native build | 210 min | 30 minutes choosing and scoping a project with the interviewer, 2 hours building it alone on your laptop, then 1 hour: a 10-minute demo, 45 minutes of code review and path to production that you lead, 5 minutes of questions |
| 4 | Code ownership |  | One of two, announced ahead: take over a teammate's PR in a small codebase and get it to shippable by finding and fixing what blocks it (debugging), or add a feature to a small existing app (feature development); you run the app locally, over Zoom |
| 5 | Work experience | 60 min | Conversation with the hiring manager that goes through your whole resume from graduation on: why each job switch, what motivated it, the engineer you respect most, and what your manager would say you are good and bad at |
| 6 | Take-home agent (agent engineer loops) |  | Build a customer-support AI agent for a made-up client and choose which features to ship; an OpenAI key is provided |
| 7 | Agent presentation (agent engineer loops) | 60 min | Half a walkthrough of your take-home agent, half a talk on a technical topic of your choice for a non-technical audience |
| 8 | Other questions |  |  |

What each round grades, its AI policy and how to prep: [Sierra interview process](https://landthelab.com/companies/sierra).
