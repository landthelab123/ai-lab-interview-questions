# Sierra interview questions and loop (2026)

8 engineering interview questions candidates report from Sierra, most recently in Nov 2026. Worked answers, a rubric per level and a prep plan: **[Sierra on Land the Lab](https://landthelab.com/companies/sierra)**.

## The loop

Built around a take-home: a recruiter call, one coding screen, a take-home customer-support agent, then an in-person onsite with a debugging round, a presentation of your agent and a hiring manager conversation. Two to five weeks from the first call to an offer is typical; the take-home adds the most time.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen | 30 min | Call |
| 2 | Technical phone screen | 60 min | One live coding problem in Python or TypeScript |
| 3 | Take-home agent |  | Build a customer-support AI agent for a made-up client and choose which features to ship; an OpenAI key is provided |
| 4 | Debugging | 60 min | A small repo that implements one feature end to end (a Python retention agent in a 2026 report, a TypeScript and React app in earlier ones) with several customer-reported bugs: reproduce each, find the root cause, fix it and prove the flow works end to end |
| 5 | Agent presentation | 60 min | Half a walkthrough of your take-home agent, half a talk on a technical topic of your choice for a non-technical audience |
| 6 | Hiring manager | 60 min | Conversation with the hiring manager that goes through your whole resume from graduation on: why each job switch, what motivated it, the engineer you respect most, and what your manager would say you are good and bad at |
| 7 | Other questions |  |  |

What each round grades, its AI policy and how to prep: [Sierra interview process](https://landthelab.com/companies/sierra).
