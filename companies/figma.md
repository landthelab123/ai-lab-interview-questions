# Figma interview questions and loop (2026)

21 engineering interview questions candidates report from Figma, most recently in Nov 2026. Worked answers, a rubric per level and a prep plan: **[Figma on Land the Lab](https://landthelab.com/companies/figma)**.

## The loop

A recruiter call, a phone stage of a 60-minute coding round and a hiring-manager chat, then an onsite of four or five rounds: pair programming, a project deep dive, one or two system designs and a behavioral round. Senior candidates add a director conversation and two references.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen |  | Call with a recruiter |
| 2 | Technical phone screen | 60 min | Pair programming in your own language against tests the interviewer provides |
| 3 | Hiring manager chat | 45 min | Behavioral conversation, alongside the coding screen |
| 4 | Coding | 60 min | One or two pair-programming rounds against provided tests |
| 5 | Project deep dive |  | Walk through a project you led |
| 6 | System design |  | Design discussion; one or two rounds |
| 7 | Behavioral |  | All-around conversation, often with the hiring manager |
| 8 | Unconfirmed |  |  |

What each round grades, its AI policy and how to prep: [Figma interview process](https://landthelab.com/companies/figma).
