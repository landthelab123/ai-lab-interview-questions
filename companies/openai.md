# OpenAI interview questions and loop (2026)

129 engineering interview questions candidates report from OpenAI, most recently in Nov 2026. Worked answers, a rubric per level and a prep plan: **[OpenAI on Land the Lab](https://landthelab.com/companies/openai)**.

## The loop

A recruiter call, then technical screens in coding (and system design for many roles), then a virtual final loop of four to six interviews: practical coding, system design, a project presentation and behavioral rounds, followed by team matching. Some onsites now add an agentic coding round, still in beta. Four to eight weeks from the recruiter call to an offer is typical; scheduling can stretch it past two months.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen | 30 min | Call with a recruiter (sometimes the hiring manager) |
| 2 | Technical screen: coding | 60 min | One problem in three to five growing parts filling the hour, usually in CoderPad; ML roles get a Colab notebook with autocomplete off |
| 3 | Technical screen: system design | 60 min | Design discussion, sometimes drawn in Excalidraw; for some roles, on the same day as the coding screen |
| 4 | Onsite coding | 60 min | Live coding; the problem often rebuilds a familiar system in several parts |
| 5 | Agentic coding (beta) |  | An existing codebase and changes too large to write by hand; you work through them with an AI coding agent |
| 6 | Onsite system design | 60 min | Design discussion |
| 7 | Project presentation | 45 min | You present one or two projects you led, usually with a few slides, then take rapid questions |
| 8 | Behavioral |  | Conversation; some loops have a second one on cross-functional work |

What each round grades, its AI policy and how to prep: [OpenAI interview process](https://landthelab.com/companies/openai).
