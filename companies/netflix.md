# Netflix interview questions and loop (2026)

43 engineering interview questions candidates report from Netflix, most recently in Oct 2026. Worked answers, a rubric per level and a prep plan: **[Netflix on Land the Lab](https://landthelab.com/companies/netflix)**.

## The loop

A recruiter call that screens culture fit, one 60-minute technical screen, then a virtual onsite of about five rounds: coding, system design, a team-specific domain or data-modeling round, and two manager or culture conversations.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen |  | Call with a recruiter |
| 2 | Technical phone screen | 60 min | Coding, practical problem solving, or SQL and pipeline design, depending on the org |
| 3 | Coding / problem solving |  | Live coding on under-specified requirements |
| 4 | System design |  | Design discussion; some loops split a general round from a team-specific one |
| 5 | Domain design or data modeling |  | Design tied to the team's domain (ads, data platform, ML infrastructure) |
| 6 | Manager and culture rounds |  | Usually two behavioral conversations |
| 7 | Unconfirmed |  |  |

What each round grades, its AI policy and how to prep: [Netflix interview process](https://landthelab.com/companies/netflix).
