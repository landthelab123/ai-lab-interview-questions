# Airbnb interview questions and loop (2026)

65 engineering interview questions candidates report from Airbnb, most recently in Nov 2026. Worked answers, a rubric per level and a prep plan: **[Airbnb on Land the Lab](https://landthelab.com/companies/airbnb)**.

## The loop

A short recruiter call, a 45-minute coding screen and often a hiring-manager screen, then a virtual onsite of coding, code review, system design and a project deep dive. A separate core-values round follows once those pass, then team matching, which can take weeks.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen | 20 min | Call with a recruiter |
| 2 | CodeSignal assessment | 90 min | Leveled project: one class with unit tests, four levels that unlock in turn |
| 3 | Technical phone screen | 45 min | One algorithm problem from a small recurring pool |
| 4 | Hiring manager screen | 45 min | Background conversation |
| 5 | Coding | 45 min | Live coding, one or two rounds, from the same pool as the screen |
| 6 | Code review | 60 min | Review two to four pull requests of growing size in Python or Java while the interviewer mostly watches |
| 7 | System design | 60 min | Design discussion |
| 8 | Experience deep dive | 60 min | One project from your resume, explored in detail |
| 9 | Core values | 45 min | Conversation with employees outside the team, scheduled after the technical rounds |
| 10 | Unconfirmed |  |  |

What each round grades, its AI policy and how to prep: [Airbnb interview process](https://landthelab.com/companies/airbnb).
