# Replit interview questions and loop (2026)

4 engineering interview questions candidates report from Replit, most recently in Oct 2026. Worked answers, a rubric per level and a prep plan: **[Replit on Land the Lab](https://landthelab.com/companies/replit)**.

## The loop

A recruiter screen (an outside agency) and team chats, an online assessment, a one-hour coding screen or a take-home discussed in the screen, then an onsite: hiring manager, live coding in an existing codebase, system design, and an AI-assisted refactoring round. Three to four weeks from the recruiter call to an offer is typical.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen |  | Recruiter call; one report adds a behavioral round on past projects and why Replit |
| 2 | Online assessment |  | Online assessment with two coding problems |
| 3 | Technical phone screen | 60 min | One algorithm problem solved with the interviewer |
| 4 | Take-home |  | A take-home submitted as a repository before the screen, then discussed in it |
| 5 | Hiring manager |  | Design and behavioral conversation with the hiring manager |
| 6 | Coding |  | Onsite coding |
| 7 | System design |  | Onsite design |
| 8 | AI refactor |  | Refactoring with AI tools |

What each round grades, its AI policy and how to prep: [Replit interview process](https://landthelab.com/companies/replit).
