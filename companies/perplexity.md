# Perplexity interview questions and loop (2026)

14 engineering interview questions candidates report from Perplexity, most recently in Nov 2026. Worked answers, a rubric per level and a prep plan: **[Perplexity on Land the Lab](https://landthelab.com/companies/perplexity)**.

## The loop

A recruiter call, a demanding multi-part coding screen or assessment, then a virtual onsite of coding, search-and-AI system design, LLM product design and a founder or VP round; three to five weeks overall.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Recruiter screen | 30 min | Call |
| 2 | Technical screen or assessment |  | Online assessment or live coding (often CoderPad); problems come in parts, each adding a requirement to your code |
| 3 | Coding | 45 min | Two live coding rounds |
| 4 | System design | 60 min | Design discussion |
| 5 | ML / LLM design | 60 min | Design discussion |
| 6 | Project deep dive |  | Conversation about a project you built |
| 7 | Hiring manager or founder | 45 min | Conversation, often with a founder or VP |
| 8 | Unconfirmed |  |  |

What each round grades, its AI policy and how to prep: [Perplexity interview process](https://landthelab.com/companies/perplexity).
