## The loop

A 45-minute hiring-manager conversation, an hour of hand-written backend coding over SSH (a cache in front of a database), then a 90-minute build with two interviewers where you drive AI coding agents to ship a data pipeline and a UI and present the result.

| # | Round | Length | Format |
|---|---|---|---|
| 1 | Hiring manager | 45 min | Conversation about your background |
| 2 | Hand coding | 60 min | VS Code over SSH on a small backend project; the recruiter says ahead of time that it is backend and database work |
| 3 | Mini project with AI agents | 90 min | Two interviewers watch; an SSH machine with a dataset, an embeddings API and two coding agents preloaded with about $500 of credit |

What each round grades, its AI policy and how to prep: [Physical Intelligence interview process](https://landthelab.com/companies/physical-intelligence).
